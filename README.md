# cartea-daliei-event-prep
Preparation materials for the Cartea Daliei event; presentation to be added by the owner.

## Public presentation

View and share: https://dragoshont.github.io/cartea-daliei-event-prep/

- Fourteen slides in a keyboard-accessible web viewer, with visible-text alternatives.
- Speaker notes are excluded from the current website, slide data and downloadable PowerPoint.
- Sources remain available in `credits.html`; narration, stage directions and private preparation records are kept separately.
- A fictional school-event page for the creation/revision/verification demonstration.
- Public references and historical photograph attribution in `credits.html`.

The event in the demonstration is fictional. Its two versions are prepared examples,
not live Copilot output. The demo contains no signup form or backend.

GitHub Pages serves the root of the `main` branch. No build dependencies are required.
